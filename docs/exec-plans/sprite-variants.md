## P3-4 で直したこと（ユーザー目線の見直し）

| 気づいた点 | 対応 |
|---|---|
| 何から始めればよいか分からない | マトリクス上部に「素体 → 領域マスク → 差分」の進み具合と次の一手のボタン |
| 一括生成がマスク未作成で黙って止まる | 実行前に、作れないセル（マスクなし・領域なし）を警告し、マスク作成へ誘導 |
| 素体を作り直すと子の差分が古いまま | 古い親から作ったセルに印を付け、「親が変わったセルを選択」でまとめて作り直せる |
| 組み合わせが爆発する（RPG テンプレートで 540 セル） | ポーズごとに使う軸を選べる（`skipAxes`） |
| 拘束・首絞めなど敵が登場するポーズ | ポーズごとに左パネルのキャラを出す／出さないを選べる（`characterIds`） |
| ポーズ違いで顔・服がずれる | V4.5 では最初のポーズの素体をキャラ参照に使える（任意・有料） |
| 手持ちの絵の縦横比がセットと違う | 最初の画像ならセットのサイズを合わせる。それ以外は警告 |
| 画像のあるポーズ・軸をうっかり消す | 削除前に確認 |
| 数百セルをマウスだけで回すのがつらい | キー操作（矢印・Enter・Space・1〜9 で採用） |
| 起動直後の StrictMode 再マウントでセットが作れない | ページ離脱時のリセットを同期にして、再マウント後の読み込みを消さないように修正 |

## P3-6 透過と文字の抑制（2026-09-30 実 API 検証、0 Anlas）

| 検証 | 結果 |
|---|---|
| V4.5 に `transparent background` | 透過にならない（3/3 白い無地背景。`simple background, white background` と同等） |
| V5 の透過生成 | 2/2 きれいに透過（約 60% が alpha 0） |
| V5 で透過画像をインペイント | 透過のまま（透過フラグなしでも保たれる）→ 素体から差分まで透過で作れる |
| 緑背景（クロマキー） | 背景は均一だが髪や輪郭が緑に染まる → 白背景を採用 |
| 立ちポーズでの文字の混入 | V4.5 / V5 とも 0/6（`no text` の有無によらない） |
| 被弾・疲労のプロンプト | 文字ではなく、効果線・息・衝撃・「!」が入る（V4.5 3/3、V5 3/3） |
| ネガティブに文字・効果線タグ | V4.5 で記号入り 3/3 → 1/3。ポジティブに motion lines があると V5 は残る → テンプレートから削除 |

実装:
- セット設定「背景」（透過 / 白背景のまま / 指定しない）: 透過は V5 なら透過生成、V4.5 なら白背景で生成（`lib/sprite/background.ts`）。
- セット設定「文字・効果線を入れない」（既定オン）: 左パネルのセリフ・効果音・記号を使わず（`plainImage`）、`no text` を必ず付け、文字・効果線タグをネガティブに入れる。有効な間は左パネルのセリフ・効果音の入力欄を隠す。
- 書き出し時の背景除去（`services/sprite_background.rs`、無料・約 25ms/枚）: 縁の中央値を背景色とし、縁からの塗りつぶし → 囲まれた無地の隙間（任意）→ 2px の縁を前景との比で半透明にして背景色を除く → キャラから離れた小さな要素（文字・サイン・効果線、任意）を消す。透過済みの画像と、背景が無地でない画像はそのまま。
- 右パネル・書き出しタブの「透過を確認」で、書き出しと同じ処理の結果を確認できる（`preview_sprite_background`）。
- NovelAI の背景除去（有料、832×1216 で約 65 Anlas/枚）は「採用画像を加工」に残す。無地でない背景用。

## P3-7 破損以外の服・体の差分（2026-09-30 実 API 検証、V5 インペイント、0 Anlas）

| 検証 | 結果 |
|---|---|
| 下着が見える破損3の画像に `stained panties`（下着の直後） | 2/2 シミが付く。破損状態・下着の色は保たれる |
| 素体のブラウスに `wet clothes, see-through` | 2/2 濡れて透ける |
| 素体の上着に `blood on clothes` | 2/2 血の染み |

実装:
- 軸に `partIds`（服のパーツにつける）。タグはそのパーツの直後に入り、パーツが隠れている（下に着ていて覆うパーツが無傷・破れ）か無い段階では入らない。そのセルは作らない（`partHidden`）。
- 派生元は「作られるセル」を親に選ぶ（パーツ軸を破損軸より上に並べても、見えない段階を親にしない）。合成も見えないセルを素材元にしない。
- 書き出しでは、見えない組み合わせにも同じ見た目のセル（パーツ軸を 0 にしたセル）の画像を割り当てる（ゲーム側でどの組み合わせを引いても画像がある）。
- 衣装セクションに「服の破損差分を作る」スイッチ（破損軸の追加／削除）。
- 「よく使う差分から追加」: 体（傷・汚れ・汗）、顔（表情・赤面・恐怖・疲労）、服（濡れ・血・汚れ → 下に着ていないパーツ）、下着（シミ → 下に着ているパーツ）。領域・段階・プロンプト設定済み（`lib/sprite/axis-presets.ts`）。

## P3-8 差分の見本

- セット名の横・最初の画面の「見本」から開く（`SpriteSampleDialog`、データは `lib/sprite/sample.ts`）。
- 画像は `src/assets/sprite-samples/`（WebP、416×608、透過、計約 750KB）。2026-09-30 に V5・透過・Opus 無料枠（0 Anlas）で生成: 素体 2 枚（立ち・指差し）→ 服の領域／顔の領域のインペイント 16 枚 → 顔の合成 1 枚（アプリの合成と同じく顔の領域を切り貼り）。表情は顔の拡大サムネイル。
- 見た目は `rakugaki` の画風タグ＋キャラ（cynthia (pokemon)）＋制服。アーティストタグは使っていない。
- 「この構成でセットを作る」で見本と同じポーズ・衣装・破損段階・表情・傷・服の血（ブレザーにつける）のセットを作り、見た目のプロンプトをクリップボードへコピーする（`sampleSpec()`）。
