## P3-4 で直したこと（ユーザー目線の見直し）

| 気づいた点 | 対応 |
|---|---|
| 何から始めればよいか分からない | マトリクス上部に「素体 → 領域マスク → 差分」の進み具合と次の一手のボタン |
| 一括生成がマスク未作成で黙って止まる | 実行前に、作れないセル（マスクなし・領域なし）を警告し、マスク作成へ誘導 |
| 素体を作り直すと子の差分が古いまま | 古い親から作ったセルに印を付け、「親が変わったセルを選択」でまとめて作り直せる |
| 組み合わせが爆発する（RPG テンプレートで 540 セル） | ポーズごとに使う軸を選べる（`skipAxes`） |
| 拘束・首絞めなど敵が登場するポーズ | ポーズごとに左パネルのキャラを出す／出さないを選べる（`characterIds`） |
| ポーズ違いで顔・服がずれる | V4.5 では最初のポーズの素体をキャラ参照に使える（任意・有料） |
| 手持ちの絵の縦横比がセットと違う | 最初の画像ならセットのサイズを合わせる。それ以外は警告 |
| 画像のあるポーズ・軸をうっかり消す | 削除前に確認 |
| 数百セルをマウスだけで回すのがつらい | キー操作（矢印・Enter・Space・1〜9 で採用） |
| 起動直後の StrictMode 再マウントでセットが作れない | ページ離脱時のリセットを同期にして、再マウント後の読み込みを消さないように修正 |
